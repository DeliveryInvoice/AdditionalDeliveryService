# AdditionalDeliveryService

## 테스트용 배송지 주소

앱의 주문 등록 화면에서 **배송 지역**은 목록에서 선택하고, **상세주소**에는 표의 상세주소를 입력합니다.

| 확인 | 장소 | 배송 지역 | 상세주소 | 담당 기사 |
|:---:|---|---|---|---|
| [ ] | 대전역 | 대전 | 동구 중앙로 | D002 (이기사) |
| [ ] | 광주 DCC | 광주 | 서구 치평동 상무누리로 | D005 (정기사) |
| [ ] | 대전 DCC | 대전 | 유성구 엑스포로 | D002 (이기사) |
| [ ] | 남산타워 | 서울 | 용산구 남산공원길 105 | D001 (김기사) |
| [ ] | 다이아몬드 타워 | 부산 | 중구 용두산길 | D004 (최기사) |
| [ ] | 성심당 본점 | 대전 | 중구 대종로480번길 | D002 (이기사) |
| [ ] | 광주 사직공원 | 광주 | 남구 사직길 49 | D005 (정기사) |
| [ ] | 서울역 | 서울 | 중구 한강대로 405 | D001 (김기사) |
| [ ] | 엑스포타워 | 대전 | 유성구 엑스포로 엑스포타워 | D002 (이기사) |
| [ ] | 서울대학교 | 서울 | 관악구 관악로 | D001 (김기사) |

## 배송기사 계정 (테스트용)

| 기사번호 | 이름 | 비밀번호 | 담당 지역 |
|---|---|---|---|
| D001 | 김기사 | 1234 | 서울, 경기, 인천 |
| D002 | 이기사 | 5678 | 대전, 세종, 충북, 충남 |
| D003 | 박기사 | 1111 | 대구, 경북 |
| D004 | 최기사 | 2222 | 부산, 울산, 경남 |
| D005 | 정기사 | 3333 | 광주, 전북, 전남 |
| D006 | 강기사 | 4444 | 강원, 제주 |
